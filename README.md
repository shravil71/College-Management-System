# College Management System

A simple **College Management System developed in C** to manage basic information about students, teachers, and staff.

This project was created as a learning project to practice fundamental C programming concepts and build a practical console-based application.

## 🚀 Features

* Add student records
* Add teacher records
* Add staff records
* Display stored records
* Manage basic college information
* Menu-driven console interface
* User input handling

## 🛠️ Technologies Used

* **Language:** C
* **IDE:** Visual Studio Code
* **Compiler:** GCC
* **Operating System:** Windows

## 📚 C Concepts Used

This project demonstrates the use of:

* Variables and data types
* Conditional statements
* Loops
* Functions
* Structures (`struct`)
* Arrays
* Strings
* `scanf()` and `fgets()`
* Input handling
* Basic string manipulation

## ▶️ How to Run

### Using GCC

Open the project folder in the VS Code terminal and compile the program:

```bash
gcc main.c -o college_management
```

Then run it:

### Windows

```bash
college_management.exe
```
